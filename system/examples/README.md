# Schema examples

These examples are schema-valid illustrations, not canonical vault content. Unless an example is explicitly marked **resolvable**, source IDs, hashes, and paths are synthetic placeholders and will not pass `evidence-vault validate` if copied into `observations/`, `wiki/`, or `memory/` as-is.

Ecology and history observation examples deliberately demonstrate that the core observation model has no finance-specific fields. End-to-end resolvable ecology and history flows live under `tests/fixtures/` and `tests/test_observe.py` (ingest real fixture bytes, then `observe`).
